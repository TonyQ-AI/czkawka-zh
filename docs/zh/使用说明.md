# Czkawka 中文定制版 — 使用说明

> czkawka-zh（基于 qarmin/czkawka 12.0.1 定制）是一款面向中文用户的**重复/相似照片筛查工具**。

本定制版在 czkawka 基础上做了以下增强（针对个人照片库去重场景）：

## 新增 / 定制功能

### 1. 自动建议保留最清晰照片（核心功能）
- 相似图片结果中，每个重复组内的照片**按清晰度从高到低自动排序**
- **清晰度判定规则**：先看分辨率（宽 × 高），分辨率相同则看文件大小
- 每组第一行自动标记 **⭐「建议保留」**，通常就是最高分辨率/最清晰的那张

### 2. 一键采纳 + 手动覆盖
- 点击工具栏 **「保留最清晰一张，选择其余所有项」**，自动勾选每组里除最清晰外的所有副本
- 你也可以**逐行点勾选框**手动决定保留哪一张（比如想留下加了滤镜的版本）

### 3. 安全批量清理
- **移到回收站**（默认，可恢复）、**移到文件夹**、**永久删除**（需勾选「我了解」并二次确认）
- 只处理你勾选（未保留）的项，⭐ 建议保留的照片绝不会被删除

### 4. 定制项
- **中文界面**：自动跟随系统语言，简体中文完整
- **按钮悬浮提示**：顶部操作按钮鼠标悬停显示功能说明（中英双语）
- **定制图标**：exe 已嵌入专属图标（蓝底 + 重叠照片 + 绿对勾）
- **「不规范名称」工具已隐藏**：该功能会把中文文件名误判为「不规范」，对中文用户不适，已从左侧工具栏移除
- **损坏文件检测修复**：内容为 PNG 但后缀为 .jpg 的真实图片不再被误报为损坏（按内容识别格式而非仅看扩展名）

## 快速开始

### 扫描重复照片
1. 启动 `krokiet.exe`，等待中文界面加载
2. 左侧工具栏选 **「相似图像」**
3. 顶部添加照片文件夹到「包含的路径」
4. 点 **「扫描」**，等待结果分组显示
5. 查看结果：每组自动排好序，⭐ 标记最清晰的一张

### 清理重复项
1. 点 **「保留最清晰一张，选择其余所有项」** 或手动勾选要清理的副本
2. 选 **「回收站」**（推荐）或「移动」或「永久删除」
3. 永久删除需勾选「我了解」确认框
4. 完成，释放磁盘空间

## 构建

```bash
# 需要 Rust 1.94.1+（推荐）
cargo build --release -p krokiet
# 产物：target/release/krokiet.exe
```

## 主要新增/修改的文件

| 文件 | 作用 |
|------|------|
| `czkawka_core/src/tools/similar_images/similarity_ranking.rs` | 清晰度评分纯函数 + 单元测试 |
| `krokiet/src/connect_scan/similar_images.rs` | 结果按清晰度排序、⭐ 标记 |
| `krokiet/src/connect_select/mod.rs` | 「保留最清晰」选择逻辑 |
| `krokiet/ui/popups/popup_delete.slint` | 永久删除双重确认弹窗 |
| `krokiet/ui/screens/action_buttons.slint` | 按钮悬浮提示 |
| `krokiet/ui/screens/left_side_panel.slint` | 工具栏（隐藏「不规范名称」） |
| `krokiet/build.rs` + `krokiet/icons/` | exe 图标嵌入 |
| `czkawka_core/src/tools/broken_files/core.rs` | 损坏图片按内容识别（修复误报） |
