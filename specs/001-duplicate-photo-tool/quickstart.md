## 环境前提

- Windows x64，Rust 工具链 ≥1.94.1（本机 1.97.1 已验证）
- 首次构建需访问 crates.io（本机走代理 `http://127.0.0.1:7897`）

## 1. 构建

```bash
# 仓库根目录
cargo build --release -p czkawka_core   # 评分模块与测试可先行验证
cargo build --release -p krokiet        # 完整 GUI（首次 20-40 分钟）
```

预期产物：`target/release/krokiet.exe`

## 2. 单元测试（评分逻辑）

```bash
cargo test -p czkawka_core similar_images::similarity_ranking
```

预期：全部通过（覆盖同分辨率、不同分辨率、0 尺寸、稳定排序、空组）。

## 3. 端到端主流程验证（GUI 冒烟）

准备测试目录（如 `C:\tmp\photo_test`）：

- 2 张完全相同的图（不同文件名和大小）
- 同一画面 3 个分辨率版本（如 1000×800、800×600、500×400）
- 1 张独有图片（不应进任何组）
- 1 张损坏/不可解码图片（应排组末、不被建议保留）

操作步骤：

1. 启动 `krokiet.exe`，确认界面为**中文**
2. 切到 "Similar Images"（相似图片）页，选择测试目录，保持默认参数点扫描
3. 预期：
   - 完全相同的 2 张出现在同一组 ✓
   - 3 个分辨率版本出现在同一组，按清晰度从高到低排列 ✓
   - 每组第一行带 ⭐ 建议保留标记（应为最高分辨率版本）✓
   - 损坏图片排在组末且无 ⭐ ✓
   - 独有图片不在任何组中 ✓
4. 手动点选某组内的另一行 → ⭐ 标记移动 ✓
5. 不勾选"永久删除"，点击"移到回收站" → 未保留项进入回收站且可恢复，保留项留在原位 ✓
6. 再次扫描确认噪声已消失（组内余留项仍在）✓
